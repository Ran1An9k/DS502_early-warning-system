# what is predict this model?

 * Risks

- Predict academic support indicator.

## Users
- Academic Advisors

## Allowed Use
Prioritising advisor review.

## Prohibited Use

- Suspension decisions
- Registration blocking
- Student-facing scores

## Model

Logistic Regression

## Metrics

- Precision
- Recall
- F1
- PR-AUC

## Limitations
- Uses proxy outcome.
- Historical bias may exist.
- Not causal.
